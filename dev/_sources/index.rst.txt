**fsstats**
===========

fsstats is an `open-source Python package <project github_>`_ for univariate and mass-univariate statistical modeling and inference for `FastSurfer <fastsurfer_>`_ and `FreeSurfer <freesurfer_>`_ imaging data.

Installation
------------

fsstats is available on `Pypi <project pypi_>`_ and can also be installed from
source.

.. tab-set::

    .. tab-item:: Pypi

        .. code-block:: bash

            pip install fsstats

    .. tab-item:: Source

        .. code-block:: bash

            pip install git+https://github.com/Deep-MI/fsstats
